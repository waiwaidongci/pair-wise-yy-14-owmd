# hxyfront-62013 木结构榫卯构件测绘

源提示词编号：8

开发一个古建筑木结构榫卯构件测绘前端项目，测绘人员可以录入建筑名称、构件编号、木材种类、榫卯类型、截面尺寸、病害位置、变形情况和修缮建议。页面需要有构件清单、榫卯类型筛选、尺寸记录表、病害标记图和单栋建筑的构件关系视图。

## 临时支撑巡检与复位放行

补测后支撑状态不再依赖口头确认。测绘页新增巡检登记、复测判定与复位放行：

- 登记支撑编号、横/纵位移（mm，带符号）、倾斜方向、巡检时刻与巡检人
- 一个支撑销记前不接第二件：占用中的支撑不能支顶其他构件，放行/销记后自动回收
- 横向或纵向位移超过 3mm：读数保留，构件转「待复测」
- 读数时刻早于或等于上一回：本次读数拒收、不登记，原记录保留，转待复测
- 贯穿裂缝构件：复测须换人、与上一回间隔不少于 2 小时，横纵两个方向都回落，才转为「可复位」并放行拆撑
- 补测尺寸或换支撑后原结论立即失效（留档标记），转待复测重新评估
- 构件清单可筛「待复测」「可复位」；单栋建筑关系图对异常构件同步描边并打 `!`
- 操作流水只追加：拒收、复测、放行、补测、换撑全部留痕，数据存 localStorage，可一键重置演示数据

## 分层结构（规则、存档、页面分别承载）

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 规则层 | `src/rules/supportRules.ts` | 纯函数：3mm 限值、读数时序校验、贯穿裂缝四闸门（换人 / 隔2小时 / 横纵回落）、状态流转，不含 React 与存储 |
| 存档层 | `src/archive/archive.ts` | 构件档案、支撑占用、读数与结论版本（只追加，失效仅标记）、操作流水、localStorage 持久化、演示种子 |
| 页面层 | `src/ui/SurveyPage.tsx`、`src/ui/RelationGraph.tsx`、`src/ui/StatusBadge.tsx` | 巡检/复测登记表单、实时闸门提示、放行与销记操作、清单筛选、关系图标异常 |
